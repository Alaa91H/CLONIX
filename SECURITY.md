# Security Policy

Security reports are taken seriously.

## Supported code

Security fixes are evaluated against the current default branch. Maintained releases may also receive fixes when practical and appropriate for the issue.

## Reporting a vulnerability

Please **do not open a public issue** for a suspected vulnerability.

Use GitHub's private **Report a vulnerability / Security advisory** flow when it is available for this repository. If that option is unavailable, contact the maintainer privately using a contact method listed on the GitHub profile.

Include, when possible:

- affected version, tag, or commit;
- device / operating-system information when relevant;
- a concise description of the impact;
- reproducible steps or a minimal proof of concept;
- relevant logs with secrets and personal data removed;
- any known workaround.

## Disclosure

Please allow reasonable time for triage, reproduction, remediation, and release coordination before public disclosure. Reports made in good faith are appreciated.
